TROUBLESHOOTING
═════════════════════════════════════════════════════════════════

Port 5173 still in use?
  lsof -i :5173 | grep -v COMMAND | awk '{print $2}' | xargs kill -9
  
Then restart:
  PORT=5173 npm start

Port 3000 in use (React):
  Vite will try 3001, 3002, etc. automatically
  
Or explicitly set:
  VITE_PORT=3005 npm run dev
