🎯 API ENDPOINTS OVERVIEW
═══════════════════════════════════════════════════════════════════════════

Health Check:
  GET /health

Orders:
  POST   /api/orders                 Create new order
  GET    /api/orders                 Fetch all orders
  GET    /api/orders?status=pending  Filter by status
  GET    /api/orders/:id             Get specific order
  PUT    /api/orders/:id/status      Update order status
  DELETE /api/orders/:id             Delete order

Tables:
  GET    /api/tables                 All tables
  GET    /api/tables/:id             Get specific table
  PUT    /api/tables/:id/status      Update table status
  GET    /api/tables/:id/orders      Get table's orders

Payments:
  POST   /api/payments               Record payment
  GET    /api/payments               All payments
  GET    /api/payments?order_id=1   Filter by order
  GET    /api/payments/:id           Get specific payment

Dashboard:
  GET    /api/dashboard/summary      Revenue, stats, occupancy

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Issue: Port 5000 already in use
Fix:   PORT=3001 npm start

Issue: Module not found errors
Fix:   npm install

Issue: Database locked
Fix:   rm db/cafeos.db-shm db/cafeos.db-wal && npm start

Issue: Can't connect from React
Fix:   Check BASE_URL, ensure server is running, verify CORS

For more help: See README.md Troubleshooting section
